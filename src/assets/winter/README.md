# Advent calendar stickers

Each `*.png` here is shown behind an opened door of the Advent calendar (`src/ui/parts/AdventCalendar.svelte`),
in turn by file name: door n gets the ((n - 1) % count)-th, so with 12 files doors 12 and 24 get `12-tree.png`.
16 × 16 pixel art, drawn crisp (`image-rendering: pixelated`).

Only CC0 art (or a licence compatible with GPL-3.0), credited in `NOTICE.md` with its page and licence. Bundled, both CC0 1.0:
- jhanson9012, 16x16 Holiday Sprites: https://opengameart.org/content/16x16-holiday-sprites
  (01 snowflake, 02 reindeer, 03 cocoa, 05 wreath, 06 star, 07 santa, 09 campfire, 11 gift-red, 12 tree)
- Kenney, Holiday Pack 2016, roguelike tilesheet: https://opengameart.org/content/holiday-pack-2016
  (04 gift-orange, 08 gift-teal, 10 gift-green)
