# Advent calendar stickers

Any `*.png` here is shown behind an opened door of the Advent calendar (`src/ui/parts/AdventCalendar.svelte`),
in turn: door 1 the first file by name, and so on, wrapping round. Pixel art, drawn crisp (`image-rendering: pixelated`).

Only art under CC0 (or a licence compatible with GPL-3.0), credited in `NOTICE.md` with its page and licence.
Candidates (check the licence on the page before downloading):
- Kenney, Holiday Pack 2016 (CC0): https://opengameart.org/content/holiday-pack-2016
- 16x16 Holiday Sprites / Holiday Expansion Set: https://opengameart.org/content/holiday-expansion-set
- Murphy's Dad, Christmas Village (CC0): https://murphysdad.itch.io/christmas-village-asset-pack

None is bundled yet: without stickers an opened door is lit gold with its number.
