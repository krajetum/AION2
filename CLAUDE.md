# AION 2 Companion

Windows desktop tracker for recurring AION 2 (EU server) tasks, replacing a Google Sheet, plus a passive DPS meter.
Tauri 2 + TypeScript + Svelte 5 + Vite. Single user, multiple characters, everything local. License: GPL-3.0 (`LICENSE`, `NOTICE.md`).

## Commands
- `npm test` — domain + server tests, `src/**/*.test.ts` and `server/**/*.test.ts` (`node --test`, Node 24 runs `.ts` natively, no test deps)
- `npx tsc --noEmit` — type-check `.ts`; `npm run check` — svelte-check (also covers `.svelte` files)
- `cargo test -p aion2-meter` (in `src-tauri/`) — DPS meter parser tests (A2Tools' own, with byte samples from live captures)
- `cargo run -p aion2-meter --example smoke` — starts the live capture and prints updates (Linux needs libpcap)
- `cargo run -p aion2-meter --example replay -- <recording.txt>` — feeds a packet recording (Settings > Diagnostics) through the meter offline (`Engine::offline`) and prints the arena match, gathers, soul points (kind, points), the kills they placed (KILL: mob, place, map) and loots (item code, mob), kills and deaths as the app would have logged them; `--positions` also the map id and your position (fitting a map's picture); `--fights` also each boss fight's rows with hits, crit, deaths and their times (a boss is known from its spawn: a recording started after it shows none; `--target mostDamage` picks the fight anyway, without the boss-only totals)
- `cargo run -p aion2-meter --example record -- [seconds] [other] [dir]` — a packet recording from the command line (game connection + known items, `other` = also the game's other connections; default 300 s into Downloads); a line typed on stdin is a mark
- `npm run tauri dev` — real desktop app (needs Rust + MSVC; first build ~2 min)
- CI: one workflow, `.github/workflows/release.yml`, on every merge into `main` (except `.md`-only changes); a pull request runs the `check` job only, a branch without one nothing,
  so run `npm test` / `npm run check` locally before merging. Jobs: `check` (ubuntu: npm test, tsc for app and `server/`, svelte-check, then what changed) →
  `server` (only if `server/` changed: D1 migrations + deploy of the Cloudflare Worker, no version bump) and
  `release` (only if anything outside `server/` changed: `cargo test -p aion2-meter`, then bumps the patch version, commits and tags it on `main`,
  builds, signs and publishes a GitHub Release + `latest.json`, the updater endpoint). Minor/major: "Run workflow" in Actions (runs both).
  Don't bump the version by hand; pull after a merge. Version lives only in `package.json`.
  Beta channel: a merge into the long-lived `beta` branch runs the same `check` + `release` (never `server`) but builds a GitHub pre-release:
  version = next patch after the newest stable tag + `-<run number>` (`src/domain/release.ts` `betaVersion`, e.g. `0.3.109-42`: numeric, the MSI takes no letters),
  set only in the run's checkout (no commit; tag `v<version>` on the beta commit), so `releases/latest` (stable apps) never sees it.
  Every build, stable or beta, rewrites `latest-beta.json` on the pre-release `beta-channel` (made by the first run): the manifest of apps with `settings.betaUpdates`,
  always the newest of both channels (one concurrency group; a stable is above the betas before it), read by `src-tauri/src/updates.rs`.
- `npm run dev` — UI only in a browser on http://localhost:1420 (launch config `web-ui` in `.claude/launch.json`)
- `node scripts/chiptune.mjs` — redraws the Pingy theme's 8-bit sounds into `public/sounds/pingy/` (no deps; the restored beeps there are not its)
- `python3 scripts/mascots.py` — redraws the mascots' sprite sheets into `public/mascots/` (Pillow + numpy, a dev tool: the app ships only the PNGs); `python3 scripts/mascot-extras.py` — the event companions (foe, festival critter)

## Verifying changes
- Logic → `npm test`. UI → `preview_start` with `web-ui` and check it in the browser pane:
  outside Tauri, `infra/storage.ts` uses localStorage (key `aion2-companion-data`) and `toast()` logs to the console,
  so autostart, tray and real toasts can only be checked in `npm run tauri dev`.
  The DPS page shows a labelled demo fight outside Tauri (`infra/meter.ts`); real numbers only in the desktop app with Npcap and the game.
- Rust changes → `cargo build` in `src-tauri/`.

## Rules
- Never read game memory, inject code, simulate input or automate the game (ToS/anti-cheat). Tracker + notifications,
  plus the DPS meter, which may only *passively read a copy of network traffic* (Npcap/libpcap). Never decrypt traffic,
  never send packets, never hook rendering (overlay = normal always-on-top window).
- Never invent server/event times: they go in `src/config.ts` marked `TO VERIFY`.
- Resets are computed from timestamps (`lastReset` vs `lastBoundary`), never from timers, so they work after the app was closed.
- Notification "already shown" marks (`warnedEvent`, etc.): never compare a time that came from the server or the meter with `===`.
  Such times are moved onto the local clock (`localNow - serverNow`), which shifts by the latency on every sync, so an exact match
  fails and the toast repeats every sync (guild call-ups, 2026-11-15). Match within a tolerance, as `dueCallups` / `dueBossAlerts` do
  (`Math.abs(mark - time) < 60_000`), and add a test with a mark a few ms off. Exact `===` is fine only for times computed locally (`nextEvent`).
- Allowed deps: Tauri plugins notification, store, autostart, http (Steam news, the Worker; its `reqwest` for the official character search/profile in `armory.rs`), updater (tray is core); Svelte 5 (+ vite-plugin-svelte, svelte-check); the UI kit: tailwindcss + @tailwindcss/vite, tw-animate-css, bits-ui, tailwind-variants, tailwind-merge, clsx (what shadcn-svelte's components import; its CLI only through `npx shadcn-svelte@1.8.1 add <name>`), uplot (charts), @lucide/svelte (icons); @sentry/svelte, @sentry/vite-plugin; for the app crate: sentry, tracing-subscriber;
  for `src-tauri/meter`: serde, serde_json, lz4_flex, parking_lot, tracing, libloading, tokio, windows. Ask before adding any other dependency.
- Ask before deleting files, running commands outside this folder, `git init`, or publishing anything.
- UI, notifications and code comments are in English.
- Ignore `spikes/` and `~/` — unrelated to the app.
